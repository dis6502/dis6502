# DIS6502 - The Interactive MOS 6502 Disassembler

## History

This project is the successor of the Windows-only versions up to version 3.6.1 that are available on [SourceForge](https://sourceforge.net/projects/dis6502).
Starting with version 4.0, development continues in Java/Swing instead of C++/Win32.

This will enable:
- Usage on all modern platforms (Windows, Linux, macOS)
- Usage of TrueType fonts
- Support for high and dynamic screen resolutions
- Better testing
